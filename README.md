# Aqdi (عقدي)

An Arabic-first B2C interactive contract generation platform. Aqdi helps ordinary Arabic-speaking users generate legally sound contracts through a conversational wizard — no lawyer required.

## The Problem

Existing Arabic legal platforms target lawyers. Ordinary users who need a rental agreement, employment contract, or partnership agreement have no self-service option in Arabic. Aqdi fills that gap.

## Architecture Highlights

- **Conversational Wizard UI** — guided question flow that builds a contract step by step
- **Clause Variant System** — a single clause stores multiple Arabic legal text variants depending on contract context
- **70+ Contract Taxonomy** — covering the most common civil and commercial contract types in Egyptian law
- **PostgreSQL + JSONB Schema** — flexible storage for contract templates and user sessions
